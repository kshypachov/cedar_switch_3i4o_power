## Что устройство должно повторить (как mock)

- `PUT …/data`: принимает `application/octet-stream` (с параметрами типа); тело — сырые байты куска.
- Отмена установки: `cancelJob` → `409 invalid_state` после `begin` (экран показывает «уже нельзя»).
- Прерванная установка видна только через `CoprocessorStatus.last_update`; `GET /jobs/{id}` после
  перезагрузки — `404` (экран на это рассчитывает).
- `CoprocessorStatus.uart_update.reason` — `uart_usb_bridge` / `uart_flashing` / `uart_unavailable`;
  `ota.reason` — `not_implemented` (есть переводы; незнакомая причина показывается как есть).
- Проверка, упавшая по содержимому: upload `state=failed` с `error` (код + message); сообщение
  устройства показывается рядом с переводом кода.

## Открыто

- Прогресс записи на плате будет иметь `total` = размер файла; экран его просто показывает — на
  устройстве не проверено.
- Хеширование 1,47 МБ в браузере на слабом телефоне не мерилось (в jsdom — доли секунды).
- В одном окне браузера возобновление привязано к `localStorage` этого origin; при заходе по другому
  адресу устройства (другой origin) загрузка не подхватывается — устройство отвечает `busy`, экран
  предлагает удалить чужой файл.
