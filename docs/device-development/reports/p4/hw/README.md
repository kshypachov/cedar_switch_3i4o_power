# P4 — аппаратные проверки на плате B (J-Link)

Плата B: J-Link `000941000024`, консоль `/dev/cu.usbmodem5AE60208891`, USB CDC
`3543501200210047`, MAC `80:34:28:10:6a:1d`. Плата A (ST-Link) не затрагивалась.
Скрипты этого каталога обращаются только к плате B. Проверка
`grep -n "192.168.88.14\|002F002B\|STM32_Programmer_CLI\|21103\|21301" *.py`

## 4. Две ошибки образа 2

**Ручной DNS не удалялся.** Адаптер снимал ручной список
`dns_resolve_remove_server_addresses(resolver, list, NULL)`. В
`subsys/net/lib/dns/resolve.c` `idx_of_server_addr()` при `if_index == 0` пропускает
каждый слот, а при `if_index > 0` требует совпадения с интерфейсом сервера — у ручного
сервера его нет (0). Функция не может удалить ручной сервер ни при каких аргументах.
Исправление: при снятии ручного списка контекст закрывается `dns_resolve_close()`;
следующий `reconfigure` (ручной список или продление аренды) делает его активным снова.

**Сеть не поднялась после сброса.** Консоль `logs/14`: в 00:00:08.8–09.4 семь раз
`W5500 frame length 65533 exceeds 65535 buffered bytes, dropped`, затем 53 раза
`Invalid W5500 header size 0` до конца записи. `Sn_RX_RSR` = 65535 и длина 65533
невозможны (буфер сокета меньше) — по SPI читаются единицы. W5500 и ESP-Hosted — на
одном SPI2 (`zephyr.dts`: `w5500@0` и `esp-hosted-mcu@1` под `spi@40003800`), C6 без
прошивки; причина не установлена. Патч v1 в этом состоянии записывал
`Sn_RX_RD = off + Sn_RX_RSR` из прочитанных единиц и уводил указатель от данных;
дальше каждый заголовок читался как 0, а исходная ветка драйвера `header <= 2` только
логирует и выходит, не трогая указатель. На первом старте образа 2 то же явление
(43 отброса) сеть не сломало — повезло со значениями.

Патч v2/v3 (`patches/README.md`, «The receive-state patch»): заголовок `<= 2`, больше
`Sn_RX_RSR` или больше кадра → `CLOSE` и `OPEN` сокета 0 (OPEN сбрасывает указатели
приёма; `Sn_MR` сохраняется). v1 снят `git apply -R` своим же файлом, v2 и затем v3
применены `west patch` списком из одной записи; `git status` дерева zephyr не менялся,
кроме `eth_w5500.c`.
