# План разработки веб-интерфейса Cedar

Дата: 2026-09-12. Статус: проект плана и API v1, реализация не начата.

Документы:

- [План, архитектура, стратегия тестирования и критерии готовности](development-plan.md).
- [Поведение API и сценарии обмена](api-contract.md).
- [OpenAPI 3.1: запросы, ответы, типы и ошибки](openapi.json).

Основой служат текущие исходники приложения, локальные деревья Zephyr/Matter/ESP-Hosted и память Claude. Проверки на плате в рамках подготовки плана не выполнялись. Отметки о старых аппаратных проверках не означают, что текущая сборка работает.

Подтверждено владельцем: только перечисленные функции обслуживания, локальная сеть и пароль администратора, загрузка файла браузером в STM32. Реле управляются через Matter. Скачивание прошивки по URL, веб-управление реле и настройка входов не включены в оценку. Существующая работа реле, входов и Matter должна сохраняться.

Решения владельца, учтённые в плане:

- ESP32 прошивается **только по UART**; ESP-Hosted OTA спланирован и описан, но реализуется после первой версии.
- UART flasher — библиотека `espressif/esp-serial-flasher` v2.0.0, подключаемая как west-модуль через `zephyr/submanifests/`.
- Образ прошивки C6 хранится файлом в LittleFS; при нехватке места раздел расширяется.
- Фронтенд пишется с нуля, существующий submodule не используется.
- HTTPS не реализуется: работа по HTTP в доверенной локальной сети.
- SoftAP нужен и реализуется этапом P7, после подтверждённой на плате прошивки по UART из веб-интерфейса.
- Весь новый код покрывается тестами: симуляция под Twister/`native_sim`, аппаратные проверки на плате или оба варианта.
